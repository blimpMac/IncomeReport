# UI/UX Pro Max design application

UI/UX Pro Max was used as a design-review input rather than a runtime UI dependency.

- Information density: financial data first, graphics second.
- Navigation: one task per page with a persistent, narrow sidebar.
- Visual hierarchy: page title -> KPI row -> primary table -> remarks/actions.
- Color: slate neutrals with semantic green/amber/red status only.
- Tables: 10 rows per page, horizontal overflow on small screens, tabular money values.
- Controls: consistent 40px-ish height, short labels, no decorative gradients.
- Responsive behavior: cards stack, controls wrap, table remains scrollable.
- Accessibility: high contrast text, visible borders, native form controls, textual status labels.
